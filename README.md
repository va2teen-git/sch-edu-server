# School Educational Server (sch-edu-server)

## О проекте
`sch-edu-server` — это кроссплатформенный образовательный веб-сервер для проведения интерактивных уроков информатики. Платформа разработана специально для нужд школ и предоставляет уроки с теорией, встроенную проверку заданий и кода (autograding), а также подробную панель мониторинга для учителя.

Главная архитектурная особенность системы — **Zero-Dependency развертывание (развертывание без зависимостей)**. Сервер поставляется в виде одного скомпилированного исполняемого файла (`.exe` для Windows и бинарного файла для ALT Linux). Это позволяет учителю информатики запустить полноценную LMS-систему в любом компьютерном классе двойным кликом мыши, без необходимости устанавливать Python, Docker, виртуальные окружения или базы данных.

## Разработка и Репозиторий

Данный проект размещается и разрабатывается на **GitHub**. 

**Важное замечание по настройке Git:** 
При работе с репозиторием (pull/push) рекомендуется явно указывать прямой (абсолютный) путь к вашим SSH-ключам в конфигурации SSH (например, в файле `~/.ssh/config`), чтобы избежать проблем с авторизацией в разных окружениях.
