По теме: "Помехоустойчивые коды"

1. Бит четности (Parity Bit)

К сообщению добавляется 1 проверочный бит. Сумма всех битов в сообщении должна быть четной. Это позволяет только обнаружить ошибку, но не исправить.

2. Код с повторением (Repetition Code)

Каждый бит передается несколько раз (например, 3 раза). Работает "правило большинства". Это позволяет исправлять ошибки, но скорость передачи падает.

3. Код Хэмминга (Hamming Code 7,4)

Позволяет не только найти ошибку, но и исправить её. В коде (7,4) передается 4 бита данных и 3 проверочных бита.

Как вычислить синдром (позицию ошибки):

Складываем значения битов на нужных позициях:
- S1 проверяет биты: 1, 3, 5, 7
- S2 проверяет биты: 2, 3, 6, 7
- S3 проверяет биты: 4, 5, 6, 7

Если сумма нечетная, пишем 1 (есть ошибка). Затем вычисляем общую позицию ошибки по формуле:
Позиция = S3 * 4 + S2 * 2 + S1 * 1
