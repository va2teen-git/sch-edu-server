# Архитектура и Выбранные Технологии

## 1. Бэкенд (Серверная часть)
*   **Фреймворк:** `Python` + `Flask`. Выбран за легковесность и простоту.
*   **База данных:** `SQLite` с включенным режимом **WAL** (Write-Ahead Logging). Обычный SQLite блокирует базу при записи, но режим WAL позволяет десяткам учеников одновременно отправлять результаты без ошибок блокировки. База данных представляет собой один файл `hamming_logs.db` (или `school_data.db`), который создается в той же папке, откуда запущен сервер (рядом с `.exe`).
*   **Упаковка (Сборка):** `PyInstaller`. Инструмент "замораживает" интерпретатор Python, все зависимости (Flask, SQLAlchemy), HTML-шаблоны и статические файлы в один монолитный файл.

## 2. Фронтенд и Выполнение кода (Песочница)
*   **Интерфейс:** Стандартные HTML/CSS (включая Bootstrap) шаблоны + Vanilla JS.
*   **Среда выполнения кода:** **Pyodide (WebAssembly)**. 
    *   *Почему это круто:* Вместо того чтобы рисковать и запускать чужой (потенциально опасный) код учеников на сервере, мы отправляем интерпретатор Python прямо в браузер ученика. 
    *   Код компилируется и выполняется локально на машине ученика. Это гарантирует **абсолютную безопасность сервера** и **нулевую вычислительную нагрузку** на процессор сервера. Сервер только фиксирует финальный результат.
